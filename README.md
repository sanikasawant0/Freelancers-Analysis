# Freelancers Analysis — Power BI Dashboard

An interactive Power BI report analyzing a global dataset of freelancers, exploring demographics,
industry distribution, skills, pricing, and experience levels.

## 📊 Overview
This project visualizes freelancer data across two report pages, covering:
- **Freelancer demographics** — gender, country, and region breakdown
- **Industry & skills** — distribution by primary skill and industry
- **Pricing insights** — average hourly rate and rate trends
- **Experience & ratings** — experience level, years of experience, and average client rating
- **Activity status** — active vs. inactive freelancers

## 📈 Visuals Used
- Pie & donut charts (demographic breakdowns)
- Clustered column chart (industry/skill comparisons)
- Line chart (trends over experience/rate)
- Funnel chart
- KPI cards (key metrics at a glance)
- Detailed data table

## 🗂️ Dataset
Table: `global_freelancers_raw`
Key fields: `freelancer_ID`, `country`, `region`, `gender`, `industry`, `primary_skill`,
`years_of_experience`, `experience_level`, `HourlyRate_Clean`, `Average_Hourly_Rate`,
`Average_rating`, `Is_Active`, `Total_Freelancers`

## 🛠️ Tools
- Power BI Desktop (.pbix)

## 🚀 How to Use
1. Download `Freelancers_Analysis__1_.pbix`
2. Open in [Power BI Desktop]
3. Explore the report pages and interact with the visuals/filters
